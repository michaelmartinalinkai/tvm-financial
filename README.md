# TVM Financial

Internal finance dashboard for The Villa Managers (PT The Villa Managers).

- **Live app:** https://binkylinkai.com/financial/
- `app/` — the full PWA (single-file `index.html` + service worker).
- `data-snapshot.json` — snapshot of the live financial data (transactions, categories, villas, furniture, etc.). The live source of truth is the cloud state behind the app; this file is a point-in-time export.

Maintained by Binky (Link AI). Private repo — financial data, do not make public.
